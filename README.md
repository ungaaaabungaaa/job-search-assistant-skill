# Job Search Assistant skill

A resume-first job search workflow for Codex and compatible skill hosts. For any profession and country.

Upload or select a resume. Review the inferred profile. Choose goals. Get verified job matches and application drafts. Request a recurring search when your host has a scheduler.

## Install

Copy the `job-search-assistant` folder into `~/.codex/skills/`, or ask Codex Skill Installer to install that folder from this repository. Then ask:

> Use $job-search-assistant with my resume to find suitable roles.

The skill contains instructions, not a hosted service. It uses the search, files, connections, and scheduler available in your host. It does not add Gmail or LinkedIn access, guarantee jobs, or run unattended without a real scheduler. Review before sending applications.

No private resumes or applicant records are included.
